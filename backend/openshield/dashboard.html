OpenWrt router

Configure the router credentials here. Password is sent once to OpenShield, encrypted at rest, and never returned to the browser. The Gateway Connector must use the same gateway ID.

Use a dedicated rpcd account with read-only access to session.login, system.board, network.interface.dump, luci-rpc.getHostHints and luci-rpc.getDHCPLeases. Reuse the LuCI/rpcd services already installed; OpenShield does not install packages, scripts or ACL files on the router. Prefer HTTPS with a trusted certificate. The connector runs near the router and opens an outbound connection to this Node; OpenShield does not change firewall, routing, wireless or DNS settings.

OPNsense firewall

Configure a read-only OPNsense API key. The API secret is encrypted by OpenShield and never returned to the browser.

pfSense CE firewall

Requires the community pfSense REST API v2 package to be installed and configured manually. OpenShield uses its read-only endpoints; it never installs the package or changes firewall settings. The API key is encrypted at rest.

No pfSense CE firewall configured.

CrowdSec threat intelligence

Connect to the CrowdSec Local API. A bouncer API key reads decisions. Optional machine credentials enable alert history; OpenShield uses them only to log in and issue read-only GET requests.

No CrowdSec Local API configured.

Wazuh security monitoring

Connect to the Wazuh Server API. OpenShield authenticates with a dedicated API user, then reads manager status, version, and up to 500 agent records. Credentials are encrypted at rest; no agent or manager changes are performed.

No Wazuh Server API configured.

Prometheus metrics server

Read-only Prometheus HTTP API diagnostics. OpenShield checks runtime information and scrape target health; it does not import, store, or re-export metrics. Bearer token is optional and encrypted at rest.

No Prometheus server configured.

Grafana dashboards

Read-only Grafana HTTP API diagnostics. OpenShield checks instance health and lists up to 100 dashboards. It does not change dashboards, data sources, alerts, or metrics. A service-account bearer token is optional and encrypted at rest.

No Grafana server configured.
